# LoveChat (Firebase ছাড়া) — ফ্রি চ্যাট ও ভিডিও কল

কোনো অ্যাকাউন্ট, ডাটাবেস বা সার্ভার সেটআপ লাগবে না। শুধু GitHub Pages-এ ফাইল আপলোড করলেই চালু।

## চালু করার ধাপ
1. GitHub-এ নতুন **public** repository বানান (যেমন `lovechat`)।
2. এই ৫টি ফাইল **Add file → Upload files** দিয়ে আপলোড করে **Commit** করুন: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`।
3. **Settings → Pages → Branch: main / (root) → Save**।
4. কয়েক মিনিট পর `https://ইউজারনেম.github.io/lovechat/` লিংকে অ্যাপ চালু হবে।
5. ফোনে লিংক খুলে **Add to Home Screen** দিন।

## 📱 ডাউনলোডযোগ্য অ্যাপ (APK) বানানো
GitHub নিজেই ফ্রিতে APK বানিয়ে ডাউনলোড লিংক দেবে। এর জন্য আরও একটি ফাইল লাগবে: `build-apk.yml`।

1. নতুন `index.html` আপলোড করুন (একই নামে আপলোড করলে আগেরটা বদলে যাবে)।
2. repository-তে **Add file → Create new file** চাপুন। ফাইলের নামের ঘরে হুবহু লিখুন: `.github/workflows/build-apk.yml` (স্ল্যাশ `/` লিখলেই ফোল্ডার তৈরি হয়)। নিচের বড় ঘরে `build-apk.yml` ফাইলের পুরো লেখা কপি-পেস্ট করে **Commit changes** দিন।
3. **Actions** ট্যাবে "Build APK" চলতে দেখবেন। ৫–১০ মিনিট লাগে। সবুজ টিক এলে হয়ে গেছে। লাল ক্রস এলে ওই রানে ক্লিক করে এরর আমাকে দেখান।
4. repository-র মূল পাতায় ডান পাশে (ফোনে নিচে) **Releases → LoveChat APK → LoveChat.apk** ডাউনলোড করুন। সরাসরি ডাউনলোড লিংক এই রকম হবে, যা ফেসবুক/WhatsApp-এ শেয়ার করতে পারবেন:
   `https://github.com/ইউজারনেম/রিপোর-নাম/releases/latest/download/LoveChat.apk`
5. Android ফোনে ফাইলটি খুললে "Install unknown apps" অনুমতি চাইবে। অনুমতি দিয়ে ইনস্টল করুন। Play Protect সতর্কতা দিলে "Install anyway" দিন।

**মনে রাখবেন:**
- iPhone-এ APK চলে না। সেখানে ওয়েব লিংক খুলে **Add to Home Screen** দিতে হবে।
- Play Store-এ দিতে একবার $25 লাগে, তাই সরাসরি APK ডাউনলোডই সম্পূর্ণ ফ্রি পথ।
- ইনস্টল করা অ্যাপে লিংকের বদলে **ID শেয়ার** হয়। ওয়েব ভার্সন আর অ্যাপের ID আলাদা, তাই ফ্রেন্ডরা একই ধরনের (অ্যাপ বা ওয়েব) ব্যবহার করলে সুবিধা।
- কোড বদলালে বা আবার Run করলে APK নতুন করে বানিয়ে একই লিংকে আপডেট হয়ে যায়।

## কীভাবে কাজ করে
- **ID ও লিংক:** প্রথমবার ঢুকলে প্রতিজনের একটি ID তৈরি হয়। 👤 বাটন থেকে নিজের **লিংক** কপি/শেয়ার করুন। কেউ সেই লিংক খুললে আপনি তার ফ্রেন্ড লিস্টে যোগ হবেন।
- **অনলাইন তালিকা:** ফ্রি পাবলিক MQTT সার্ভারের মাধ্যমে যারা এখন অনলাইনে আছে (সব দেশ থেকে) তাদের নাম, দেশ ও বায়ো দেখা যায়। 👤 থেকে "তালিকায় দেখাবেন না" দিলে আপনি লুকিয়ে থাকবেন।
- **চ্যাট ও কল:** দুই ডিভাইসের মধ্যে সরাসরি (PeerJS)। মেসেজ কোনো সার্ভারে জমা থাকে না।
- **ইতিহাস:** চ্যাট, ফ্রেন্ড ও ব্লক লিস্ট শুধু আপনার ফোনের ব্রাউজারে সেভ থাকে।

## সীমাবদ্ধতা (জানা দরকার)
- মেসেজ পাঠাতে ও কল করতে **দুজনকেই অনলাইনে (অ্যাপ খোলা)** থাকতে হবে। অফলাইনে মেসেজ জমে থাকে না, নোটিফিকেশনও আসে না।
- ব্রাউজারের ডেটা মুছে ফেললে বা ফোন বদলালে ID, ফ্রেন্ড ও চ্যাট হারাবেন। ID লিখে রাখুন, নতুন ডিভাইসে "আগের ID" ঘরে দিলে একই ID ফিরে পাবেন (চ্যাটের ইতিহাস ফিরবে না)।
- অনলাইন তালিকা পাবলিক সার্ভারে চলে, তাই সেখানে দেওয়া নাম/দেশ/বায়ো যে কেউ দেখতে পারে। ব্যক্তিগত তথ্য লিখবেন না। সার্ভার ডাউন থাকলে তালিকা আসবে না, কিন্তু ID/লিংক দিয়ে চ্যাট ও কল চলবে।
- কেউ অন্যের নাম নকল করতে পারে, কারণ লগইন নেই। পরিচিত কাউকে চিনতে ID বা লিংক ব্যবহার করুন।
- **কোনো অ্যাডমিন বা মডারেশন নেই।** বিরক্ত করলে চ্যাট মেনু (⋮) থেকে ব্লক করুন। রিপোর্ট করার জায়গা নেই।
- কিছু মোবাইল নেটওয়ার্কে কল না লাগতে পারে। তখন একটি ফ্রি TURN সার্ভার নিয়ে `index.html` এর ওপরে `EXTRA_ICE` এ বসান।
- লগইনের সময় ১৮+ ঘোষণা আছে, কিন্তু যাচাই করা হয় না। অপরিচিতদের সাথে টাকা, ছবি বা ব্যক্তিগত তথ্য শেয়ার করবেন না।
